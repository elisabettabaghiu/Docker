# Docker
Questo repository contiene gli script Python sviluppati per l'analisi sperimentale di Docker Model Runner, lo strumento integrato in Docker Desktop per l'esecuzione locale di modelli AI in ambienti containerizzati.

AMBIENTE DI TEST
Hardware MacBook Pro Apple Silicon ARM64
Sistema operativo macOS
Docker Desktop 4.40+ (Model Runner integrato)
Modello testato ai/smollm2 — 361M parametri, quantizzazione Q4_K_M
Dimensione modello 256 MB su disco
Python versione 3.13.7
